# تطبيق لولو 🦉 — تدريب اختبار القدرات (ويب، يعمل بدون إنترنت)

تطبيق ويب (PWA) يُثبَّت على الآيفون من Safari بدون App Store وبدون رسوم. كل البيانات تبقى على الجهاز (localStorage).

## الاستضافة على GitHub Pages (مجانًا)
1. أنشئ مستودعًا باسم `lulu` في حساب GitHub (مثلًا smootlq).
2. ارفع **محتويات** هذا المجلد (index.html، app.js، ... والمجلدين fonts و icons) إلى جذر المستودع.
3. Settings ← Pages ← Source: `Deploy from a branch` ← الفرع `main` والمجلد `/ (root)` ← Save.
4. بعد دقيقة يصير الرابط: `https://smootlq.github.io/lulu/`

## التثبيت على الآيفون
1. افتح الرابط في **Safari**.
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← إضافة.
3. افتحه مرة وهو متصل بالإنترنت؛ بعدها يشتغل بدون إنترنت.

## النسخ الاحتياطي
الإعدادات ← نسخة احتياطية ← تنزيل ملف أو مشاركة. للاسترجاع: اختاري الملف أو الصقي النص.

## التحديث
عند تعديل الملفات، غيّر `VERSION` في `sw.js` حتى يتحدّث التطبيق المثبَّت.
